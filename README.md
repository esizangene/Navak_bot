# نواک | NAVAK

ربات جست‌وجوی موسیقی نواک؛ مخزن مستقل برای نسخه‌های تلگرام، بله و روبیکا.

## وضعیت فعلی
- نسخه اولیه تلگرام: جست‌وجوی نام آهنگ/خواننده و نمایش اطلاعات و پیش‌نمایش‌های ارائه‌شده از iTunes Search API.
- عضویت اجباری در کانال تلگرام پیش از استفاده.
- نسخه‌های بله و روبیکا هنوز به آداپتر و توکن/API رسمی همان پلتفرم‌ها نیاز دارند و در این نسخه فعال نیستند.
- آثار دارای حق نشر به‌صورت فایل کامل دانلود یا ارسال نمی‌شوند؛ ربات فقط لینک رسمی و پیش‌نمایش مجاز را نمایش می‌دهد.

## راه‌اندازی تلگرام
1. Python 3.11 یا جدیدتر نصب کن.
2. دستور `pip install -r requirements.txt` را اجرا کن.
3. متغیرهای محیطی را طبق `.env.example` تنظیم کن:
   - `TELEGRAM_BOT_TOKEN`: توکن ربات تلگرام
   - `REQUIRED_CHANNEL`: شناسه کانال، مانند `@NavakChannel`
   - `CHANNEL_JOIN_URL`: لینک عضویت (اختیاری)
4. ربات را در کانال ادمین کن تا بتواند عضویت کاربران را بررسی کند.
5. اجرا: `python bot.py`

## میزبانی
این ربات با polling اجرا می‌شود و به یک سرویس Worker دائمی نیاز دارد؛ هاست استاتیک یا استقرار معمولی سایت کافی نیست. توکن‌ها را فقط در بخش Environment/Secrets سرویس میزبانی وارد کن و هرگز داخل GitHub قرار نده.

## بله و روبیکا
اتصال این دو پلتفرم باید با API و توکن رسمی همان پلتفرم انجام شود. تا زمان افزودن آداپتر و تنظیم امن توکن، آن‌ها فعال نیستند.
