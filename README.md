# نواک | NAVAK

مخزن مستقل ربات موسیقی نواک برای تلگرام، بله و روبیکا.

## امکانات مشترک
- جست‌وجوی نام آهنگ یا خواننده
- نمایش عنوان، خواننده، آلبوم و پیوند صفحه رسمی
- نمایش پیش‌نمایش کوتاه در صورت ارائه از منبع
- عدم ارسال فایل کامل آثار دارای حق نشر بدون مجوز صاحب اثر

## وضعیت اتصال
- تلگرام: `bot.py` (کتابخانه python-telegram-bot)
- بله: `bale_bot.py` (Bot API سازگار با الگوی Telegram)
- روبیکا: `rubika_bot.py` (Bot API رسمی روبیکا، روش getUpdates)

کدهای بله و روبیکا به مخزن اضافه شده‌اند، اما تا زمان ساخت ربات در هر پیام‌رسان، تنظیم توکن امن و اجرای آزمایشی، فعال/آنلاین محسوب نمی‌شوند.

## راه‌اندازی
Python 3.11 یا جدیدتر و نصب وابستگی‌ها:

```bash
pip install -r requirements.txt
```

هر ربات را در یک پردازش جداگانه اجرا کن:

```bash
python bot.py
python bale_bot.py
python rubika_bot.py
```

## متغیرهای محیطی
مقادیر را در بخش Environment / Secrets سرویس میزبانی تنظیم کن؛ توکن را در کد یا GitHub قرار نده.

- `TELEGRAM_BOT_TOKEN`: توکن ربات تلگرام
- `REQUIRED_CHANNEL`: شناسه کانال تلگرام؛ در حال حاضر `@musicnavac`
- `CHANNEL_JOIN_URL`: لینک کانال تلگرام
- `BALE_BOT_TOKEN`: توکن ربات بله
- `RUBIKA_BOT_TOKEN`: توکن ربات روبیکا

برای بررسی عضویت اجباری تلگرام، ربات تلگرام باید در کانال `@musicnavac` مدیر باشد. عضویت کانال تلگرام به‌صورت خودکار برای کاربران بله و روبیکا قابل احراز نیست؛ این دو نسخه فعلاً جست‌وجوی موسیقی را بدون آن کنترل ارائه می‌کنند.

## میزبانی
این برنامه‌ها polling انجام می‌دهند و برای کارکرد پیوسته به پردازش‌های پس‌زمینه دائمی نیاز دارند. استقرار سایت استاتیک مناسب نیست. قبل از انتخاب سرویس میزبانی، هزینه و شرایط پلن را بررسی کن.
