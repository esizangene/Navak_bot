# نواک | NAVAK

مخزن مستقل ربات موسیقی نواک برای تلگرام، بله و روبیکا.

## امکانات تلگرام
- جست‌وجوی نام آهنگ یا خواننده و نمایش اطلاعات و پیش‌نمایش موجود
- بررسی عضویت در کانال @musicnavac
- ساخت لینک دعوت اختصاصی برای هر معرف با دستور /ref
- شمارش عضویت‌های جدیدی که واقعاً از لینک اختصاصی وارد کانال شوند
- جلوگیری از شمارش دوباره یک حساب در جدول معرف‌ها
- آمار شخصی با /mystats و جدول برترین معرف‌ها با /top
- هدف اولیه معرفی ۳ عضو؛ پاداش باید توسط مدیر کانال تعیین و دستی تأیید شود

## وضعیت پلتفرم‌ها
- تلگرام: bot.py و referrals.py
- بله: bale_bot.py (نیازمند توکن و آزمایش زنده)
- روبیکا: rubika_bot.py (نیازمند توکن و آزمایش زنده)

نسخه‌های بله و روبیکا فعلاً سیستم ردیابی عضویت کانال تلگرام را ندارند. کدهای اولیه آن‌ها تا زمان دریافت توکن امن و آزمایش رسمی، آنلاین یا تأییدشده محسوب نمی‌شوند.

## راه‌اندازی
Python 3.11 یا جدیدتر:

```bash
pip install -r requirements.txt
python bot.py
```

برای اجرای هر سه برنامه از python run_all.py استفاده کن. این اجراکننده فقط پلتفرم‌هایی را اجرا می‌کند که توکنشان تنظیم شده باشد.

## متغیرهای محیطی
مقادیر را در بخش Environment / Secrets سرویس میزبانی تنظیم کن؛ توکن را در کد یا GitHub قرار نده.

- TELEGRAM_BOT_TOKEN: توکن ربات تلگرام
- REQUIRED_CHANNEL: شناسه کانال، پیش‌فرض @musicnavac
- CHANNEL_JOIN_URL: لینک کانال، پیش‌فرض https://t.me/musicnavac
- DATABASE_PATH: مسیر فایل پایگاه داده دعوت‌ها؛ باید روی فضای ذخیره‌سازی دائمی باشد
- BALE_BOT_TOKEN: توکن ربات بله
- RUBIKA_BOT_TOKEN: توکن ربات روبیکا

## تنظیمات ضروری تلگرام
1. ربات را در کانال @musicnavac مدیر کن.
2. مجوز دعوت کاربران / ساخت لینک دعوت را به ربات بده.
3. برنامه رویدادهای chat_member را درخواست می‌کند؛ برای دریافت آن‌ها ربات باید مدیر کانال باشد.
4. برای حفظ آمار بعد از استقرار مجدد، DATABASE_PATH را روی دیسک دائمی یا پایگاه داده پایدار قرار بده. فایل SQLite روی فضای موقت هاست ممکن است با استقرار مجدد پاک شود.
5. برای پاداش معرفی، تعداد دعوت‌ها به‌صورت خودکار اعلام می‌شود؛ پرداخت یا اعطای اشتراک بدون بررسی مدیر انجام نمی‌شود.
